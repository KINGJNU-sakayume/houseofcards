# Decisions — Phase A

## 2026-10-18 · 실행 범위와 문서 권한

사용자는 `KINGJNU-sakayume/houseofcards` 저장소에서 첨부 문서를 기준으로 구현하라고 확인했다. 첨부 프롬프트의 `CURRENT PHASE: A`와 한 작업당 한 단계 규칙을 적용한다. 원본 첨부 문서 3개는 저장소에 보존했다. 다음 단계 구현을 시작하지 않는다.

## Foundation 프리뷰의 정직한 경계

주간 달력, 기록 확인, 세이브, 기술 기반만 동작한다. 후속 메뉴는 탐색 가능하지만 미구현 표시 외에 가짜 수치·버튼·차트를 제공하지 않는다. 매주 3~7개 실제 정치 업무 보고는 후속 시스템이 있어야 의미가 있으므로 지금은 주간 일정 안내 하나만 생성한다. 수신함은 최근 12개를 보관하고 전체 이벤트/명령 기록은 남긴다. 안내를 보냈다는 이유로 실제 정치 통계를 계산했다고 표현하지 않는다.

## 데이터와 법적 가정

현재 번들에는 정치인·정당·국회 의석·현실 지표·법률의 실제 사실 레코드가 없다. `FOUNDATION_ONLY` pack은 비어 있는 정치 데이터와 17→8 게임 권역 매핑을 명시한다. 이는 Data Tier 1을 완성했다는 의미가 아니다. 원본 문서의 2026년 법제·정당 동향 주장은 이번 단계에서 독립 검증하지 않았으며 실제 데이터로 복사하지 않는다.

검증기는 §33의 300석/공석 합계, ID/참조, 출처/검증일, 지표 기준일, 날짜 형식, 세이브 누출, 이름 충돌, 시도 매핑, 릴리스 가정값 차단을 구현한다. `FOUNDATION_ONLY`에 정치적 레코드가 들어오면 실패한다. BASELINE은 국회·정당·집권당을 요구한다. 릴리스 모드에서도 빈 foundation pack의 불완전성 경고는 유지하지만 배포를 막지는 않는다. `UNVERIFIED_ASSUMPTION`은 어느 모드의 pack에서도 릴리스 오류다. 테스트의 synthetic baseline/인물은 테스트 전용이며 번들에 포함하지 않는다.

## Ruleset와 세이브 확장

선거 프리셋 구현은 Phase D이다. Phase A는 `foundation_calendar_only`라는 명시적, 선거 계산이 불가능한 스냅샷을 저장한다. 달력만 포함하며 의석·문턱·기탁금·등록취소 값은 제공하지 않는다. 이 스냅샷을 실제 선거제도라고 표시하지 않는다. 향후 ElectionRuleset 인터페이스에는 3개 프리셋을 표현할 모든 필드와 준연동형 옵션을 마련했다. 엔진 배분 훅은 Phase D에 구현한다.

아직 존재하지 않는 정당/자원/AI/코호트/후보 등의 저장 필드는 빈 숫자로 채우지 않고 해당 단계에서 스키마를 올려 추가한다. 현재 세이브는 정확히 Phase A 스키마 1을 받아들인다. 알려지지 않은 버전은 오류로 보존하며 묵시적으로 업그레이드하지 않는다.

## 달력 산술과 사양의 77틱 불일치

독립 날짜 계산 및 경계 테스트에서 사양의 숫자 불일치를 확인했다. 2026-10-19와 2028-04-10 사이에는 539일 = 77주가 있으므로 양 끝을 포함하면 월요일 78개, 날짜 전진은 77회다. 사양의 명시적 시작일·종료일·7일 간격을 우선하고 “77틱”은 77번의 ADVANCE_WEEK로 해석한다. 새 프리뷰는 1주차이며 마지막은 78주차다. 원본 사양은 수정하지 않는다. 날짜 계산은 ISO 날짜와 명시적 UTC 자정만 사용하고 현재 시각/로컬 시간대에 의존하지 않는다. 월말 틱은 다음 월요일이 다른 달인 월요일이다. 선거일은 사양의 게임 일정이며 법률 확인을 의미하지 않는다. Phase A는 마지막 월요일에서 멈춘다.

## 결정론

RNG는 `(uint32 seed, subsystem, ISO date)`의 JSON 튜플에서 FNV-1a 32 seed를 파생하고 xorshift32와 rejection sampling으로 정수를 만든다. 스트림 위치는 세이브에 기록된다. 현재 RNG의 유일한 사용처는 가상 일정 담당 직책 선택이며 지지율/정치 결과는 없다.

상태 해시는 정렬한 키/원래 배열 순서를 가진 canonical JSON에 FNV-1a 64를 적용한다 (UTF-16 코드 유닛). 로케일 정렬, 시간, random, exp/log/pow는 결과 경로에 없다. 해시는 재생·손상 확인용이며 보안 서명이 아니다. 고정소수점 유틸은 Q6, half-away-from-zero, safe integer 범위를 사용한다. exp는 범위 ±8, /16 축소와 12항 테일러 후 4회 제곱이며 Phase B 효용 모델 도입 때 정밀도를 재검토한다.

## UI와 저장

UI는 명령만 dispatch한다. Worker는 상태와 명령을 받아 같은 순수 엔진을 호출한다. Worker 미지원/초기화 오류/8초 무응답에는 동일 명령을 메인 스레드에서 실행한다. UI에서는 실행 방식과 해시를 세이브의 접힌 진단 영역에만 표시한다.

IndexedDB 자동저장은 모든 성공한 상태 변경 후 수행한다. 수동 슬롯은 별도다. 쓰기 transaction 완료 전 성공으로 표시하지 않는다. 저장 실패 시 플레이 상태는 보존하고 JSON 내보내기 안내를 제공한다. JSON 가져오기는 파싱·스키마·해시·명령 재생을 모두 통과한 뒤에만 교체한다. 새 프리뷰/불러오기/가져오기는 교체 안내를 먼저 띄운다. 다중 탭 동시 편집은 현재 last-writer-wins이며 합치기/탭 잠금은 미구현이다.

## 배포와 CI

Vite base `/houseofcards/` + HashRouter를 선택했다. 서비스 워커 없이 로드 후 오프라인 진행을 지원한다. 전체 오프라인 재접속은 별도 범위다. `main` CI가 전부 통과하면 공개 Phase A 프리뷰를 Pages로 배포한다. 미검증 법률값이 없는 foundation-only 빌드이며 정치 데이터가 들어가는 후속 릴리스는 원본 릴리스 체크리스트를 다시 충족해야 한다.

PR/매일 검사에서 각각 20/500 시드 달력 재생을 수행한다. 이를 AI-only 선거 시뮬레이션이나 밸런스 검증이라고 부르지 않는다. Phase B 이후 실제 AI와 선거 엔진에 맞춰 확장한다.
